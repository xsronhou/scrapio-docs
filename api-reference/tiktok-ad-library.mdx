---
title: TikTok Ad Library
description: Search TikTok's Ad Library and fetch single-ad detail.
---

<Note>
  TikTok Ad Library endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/tiktok/ad-library/search` — Search by advertiser or keyword.
- `GET /v1/tiktok/ad-library/ad` — Fetch a single ad's detail by ad id.
