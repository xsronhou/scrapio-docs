title: SimplyHired

---

<Note>
  SimplyHired endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/simplyhired/jobs` — Search job listings by keywords, with an optional free-text location. Cursor-paginated.
- `GET /v1/simplyhired/job` — Fetch full detail for a single job listing by `job_id`: full HTML/plain-text description, salary, and company info.
