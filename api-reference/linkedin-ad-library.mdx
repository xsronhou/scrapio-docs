---
title: LinkedIn Ad Library
description: Search LinkedIn's Ad Library and fetch single-ad detail.
---

<Note>
  LinkedIn Ad Library endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/linkedin/ad-library/search` — Search ads by company or keyword.
- `GET /v1/linkedin/ad-library/ad` — Fetch a single ad's detail by ad id.
