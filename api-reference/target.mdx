---

<Note>
  Target endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/target/product` — Retrieve product details by Target SKU.
- `GET /v1/target/search` — Search Target.com and return structured results.
