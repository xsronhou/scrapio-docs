---
title: Built In
description: Search Built In tech/startup job listings by keywords.
---

<Note>
  Built In endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/builtin/jobs` — Search job listings by keywords. Cursor-paginated.
- `GET /v1/builtin/job` — Fetch full detail for a single job listing by `url` (the full job URL from a search response): full HTML/plain-text description, salary, benefits, and company info.
