---
title: TikTok Shop
description: Search TikTok Shop's catalog and retrieve structured product detail.
---

<Note>
  TikTok Shop endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/tiktok/shop/search` — Search TikTok Shop's catalog by keyword.
- `GET /v1/tiktok/shop/product` — Fetch structured product detail by product id or url.
