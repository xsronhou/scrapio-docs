---
title: Airbnb
description: Search Airbnb listings and retrieve structured listing details.
---

<Note>
  Airbnb endpoints require a paid plan (Starter or higher). Without one, these endpoints return `402 plan_upgrade_required`. See [Pricing](/pricing) for details.
</Note>

## Endpoints

- `GET /v1/airbnb/search` — Search Airbnb listings by location, dates, and guest counts.
- `GET /v1/airbnb/listing` — Retrieve structured detail for a single Airbnb listing.
